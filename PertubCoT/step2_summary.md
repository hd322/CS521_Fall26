# PerturbCoT 第二步完成说明

第二步已生成并整理成一份配对数据集：50 道固定 GSM8K 原题，每题 4 个答案保持型变体，共 200 条。

## 具体实现

1. 从第一步固定的 `originals.jsonl` 读取 50 道原题，并核对输入 SHA-256，防止原题在不知情时发生变化。
2. 为每道题生成四种变体：
   - 语言改写：仅改写最后的提问句，前面的数学条件逐字保留；
   - 实体改名：使用逐题替换表，对相关名称执行完整替换；
   - 格式调整：将原句按原顺序放入项目符号和问题区；
   - 添加无关信息：在原题末尾追加固定且不含数字的背景句。
3. 每个变体继承原题的 `group_id`、`split` 和 `gold_answer`。同一原题的四个变体不会跨数据划分。
4. 自动检查数量、类型、原题文本、数字序列、实体替换、句子保持、无关信息追加、审核记录和审核文本哈希。
5. Codex 逐题检查题意、条件、提问目标与答案是否保持不变。两处初稿语法问题经修正后重新生成和审核。
6. 将含答案的数据放入 `offline_eval`，将不含答案的数据放入 `runtime`；运行时生成器、监控器和验证器只能读取后者。

## 结果边界

标准答案继承自 GSM8K。变体通过“保持数字与数学关系不变”的设计来保持答案，并未将 200 个变体分别重新求解。Codex 复核不是独立人工标注；在正式论文实验冻结数据前，建议增加一名独立人工复核者。六道没有专名的原题使用普通实体替换，已在数据和说明中披露。
