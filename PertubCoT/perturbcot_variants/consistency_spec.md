# PerturbCoT 变体一致性规格 v1

本规格适用于第一版的四类答案保持型扰动。一个变体只有在数学条件、条件间关系、指代归属、单位、时间范围、提问目标和标准答案全部保持时才能进入实验。

## 通用规则

1. 每个变体直接从原题生成，只应用一种扰动。
2. 所有数字及其出现顺序保持不变。数字相同只是必要条件，不足以证明语义等价。
3. 同一原题的四个变体继承相同的 `group_id`、`split` 和 `gold_answer`。
4. 不修复原题措辞或语法问题，除非该修复本身就是预先定义的改写范围；否则可能改变难度或引入第二种扰动。
5. 无法确认等价时拒绝该变体，修改后重新执行全部检查和审核。

## 分类型规则

### 语言改写

仅重写原题的最后提问句。允许同义替换和语序调整；不得改变条件、范围、单位、时间点、平均或总量等运算语义。本版用逐题显式尾句表，不使用运行时随机生成。

### 实体改名

替换人物、组织、地点、标签或主要计数对象的名称。一个实体的全部直接名称必须一致替换，角色、代词、所有权和数量归属保持不变。多个实体不能合并或交换角色。没有专名的六题使用普通实体替换，并在报告中单独披露。

### 格式调整

只改变段落、换行、项目符号及 `Problem details`／`Question` 标签。所有原句按原顺序逐字保留。单句题只增加 `Question` 标签和项目符号。

### 添加无关信息

原题全文逐字保留，在末尾追加固定句：`The problem was written in a notebook with a blue cover.` 该句不包含数字、不指向题中实体，也不形成新的约束。

## 检查与处置

生成器对输入哈希、覆盖范围、变体数量、数字序列、文本保持、替换完整性和审核记录执行硬检查。任何硬检查失败都会终止导出。Codex 语义审核检查题意、条件、所求量和答案不变；独立人工复核作为正式实验前的第二层审核。被拒绝的变体不进入运行时文件，修改后必须生成新的清单和哈希。
